# 🚀 Personal Portfolio – React.js

A modern, responsive personal portfolio website built with **React.js** and **Vite**.

## ✨ Features

- ⚡ Built with React.js + Vite for fast performance
- 🎨 Modern dark UI with unique typography (Syne + DM Sans)
- 📱 Fully responsive layout using CSS Flexbox & Grid
- 🧩 Reusable component architecture with CSS Modules
- 🎞️ Smooth CSS animations and micro-interactions
- 🌐 Sections: Hero, Projects, Skills, Contact

## 📁 Project Structure

```
portfolio/
├── index.html
├── vite.config.js
├── package.json
└── src/
    ├── main.jsx
    ├── App.jsx
    ├── index.css
    └── components/
        ├── Navbar.jsx / .module.css
        ├── Hero.jsx / .module.css
        ├── Projects.jsx / .module.css
        ├── Skills.jsx / .module.css
        └── Contact.jsx / .module.css
```

## 🛠️ Tech Stack

- **React.js** – UI library
- **Vite** – Build tool
- **CSS Modules** – Scoped component styling
- **Google Fonts** – Syne & DM Sans

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/yourusername/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```

## 📝 Customization

1. Update your **name, bio, and email** in `Hero.jsx` and `Contact.jsx`
2. Add your **GitHub and LinkedIn** links in `Contact.jsx`
3. Replace the **projects** in `Projects.jsx` with your own
4. Adjust **colors** in `src/index.css` CSS variables
